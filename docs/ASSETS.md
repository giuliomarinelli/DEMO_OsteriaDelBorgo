# Asset e crediti

Gli asset di questa milestone sono originali e creati per il progetto:

- `public/images/il-pranzo.svg`: illustrazione vettoriale di tagliatelle e tovaglia.
- `public/images/la-tavola.svg`: studio illustrato di una tavola per due.
- `public/favicon.svg` e marchio tipografico nell'header.

Nessuna fotografia di locali reali, immagine di terzi, recensione o attestazione. Le illustrazioni sono opere dimostrative originali del progetto, disponibili insieme al codice, senza licenze di terzi da attribuire. Non rappresentano un ristorante reale. I font sono stack di sistema: nessun file font distribuito e nessuna richiesta a provider esterni. Le dipendenze software mantengono le proprie licenze nei pacchetti npm.
